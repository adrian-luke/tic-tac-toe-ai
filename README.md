# Tic-Tac-Toe AI

## Project Description
This project is a command-line Tic-Tac-Toe game written in Python. The user plays against a computer opponent with multiple difficulty levels. The program includes score tracking, replay functionality, input validation, and a clean numbered board display.

The AI is rule-based. On easier difficulty, it makes random moves. On harder difficulty, it attempts to win, block the player, take the center, or choose an available move.

## Features
- Command-line interface
- Player can choose X or O
- Easy, Medium, and Hard difficulty levels
- Score tracking for player wins, computer wins, and draws
- Replay option after each game
- Input validation for invalid moves
- Error handling for non-numeric inputs

## How to Run
1. Make sure Python is installed.
2. Download or clone this repository.
3. Open Command Prompt or Terminal in the project folder.
